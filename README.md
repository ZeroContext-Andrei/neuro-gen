# NeuroNest Genesis

## Overview

NeuroNest Genesis is an innovative mental wellness platform that leverages AI technology to deliver personalized mindfulness exercises with neuroscience-backed progress tracking. Built with modern web technologies, the application offers a seamless user experience with beautiful UI design and smooth animations.

## Features

- **AI-Powered Recommendations**: Personalized mindfulness exercises tailored to each user's unique cognitive patterns
- **Neuroscience-Backed Tracking**: Scientific measurement of mental fitness and cognitive improvements
- **Adaptive Mindfulness**: Exercises that evolve based on user feedback and results
- **Secure Authentication**: User registration and login with social media integration
- **Modern UI/UX**: Smooth animations, transitions, and responsive design

## Technology Stack

This project is built with:

- **React 18** - A JavaScript library for building user interfaces
- **TypeScript** - For type safety and enhanced developer experience
- **Vite** - Next-generation frontend tooling for rapid development
- **Tailwind CSS** - A utility-first CSS framework
- **shadcn/ui** - High-quality, accessible UI components
- **React Router** - For seamless navigation and routing
- **React Transition Group** - For page and element transitions

## Getting Started

### Prerequisites

- Node.js (v18.0.0 or later recommended)
- npm or yarn

### Installation

```sh
# Clone the repository
git clone https://github.com/yourusername/neuro-nest-genesis.git

# Navigate to the project directory
cd neuro-nest-genesis

# Install dependencies
npm install
# or
yarn install

# Start the development server
npm run dev
# or
yarn dev
```

The application will be available at http://localhost:5173 (or another port if 5173 is in use).
